# Archived Tickets

Closed tickets live here for institutional memory and auditability. **Do not schedule active work from this folder.**

| Status | Meaning |
|---|---|
| `DONE` | Acceptance criteria verified and satisfied; changes shipped |
| `OBSOLETE` | Architecture or priorities evolved; work is no longer desired |
| `SUPERSEDED` | Replaced by a subsequent ticket (referenced in `superseded_by` front-matter) |
| `ABANDONED` | Pruned from backlog with rationale recorded in the ticket's Notes Log |

Active tickets (`READY`, `IN_PROGRESS`, `IN_PLAN`, `BACKLOG`, `BLOCKED`) remain in the parent [`../`](../) directory.

Ticket IDs never change when moved here. See [`../INDEX.md`](../INDEX.md) for the active index.
