# Tickets Index

Curated registry of **active** tickets. When a ticket moves to a terminal state (`DONE`, `OBSOLETE`, `SUPERSEDED`, `ABANDONED`), move the ticket file to [`archive/`](archive/) and remove or archive it from this index.

See [`README.md`](README.md) for lifecycle and ticket rules. New tickets use [`_TEMPLATE.md`](_TEMPLATE.md).
